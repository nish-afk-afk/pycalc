# PyCalc

A very simple Python-coded terminal calculator.

## Features

1. Addition
2. Subtraction
3. Multiplication
4. Modulo (using `%`)
5. Division
6. Continuous calculations

### Commands

**Note:** All commands have to be executed from the `"Enter operation symbol"` prompt.

1. `exit` — closes PyCalc
2. `reset` — resets the first number and asks for it again

#### Requirements

1. Python 3
2. Only Windows and Linux are guaranteed to work. Other operating systems may require special dependencies.

##### Guide on How to Set Up

**Windows:** Making a build with PyInstaller or using the official Python application is recommended.

**Linux:** Giving the file executable permissions from Bash, Zsh, or Fish is recommended.
